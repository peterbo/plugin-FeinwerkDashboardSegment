__Does it change my existing dashboards?__

No. Until you pick a segment for a widget or set a dashboard default, everything behaves exactly like standard Matomo.

__Which segments can I use?__

Every saved Matomo segment you are allowed to see for the website. The picker sits in the widget header.

__Can the same widget appear twice with different segments?__

Yes. Add the widget twice and give each copy its own segment, for example to compare all visits with mobile visitors side by side.

__What do anonymous visitors of a public dashboard see?__

The dashboard with its normal segment. Segment choices belong to signed-in users, so the plugin stays inactive for anonymous visitors.
